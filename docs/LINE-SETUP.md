# คู่มือตั้งค่า LINE สำหรับ Challenge Me

เอกสารนี้บอกทีละขั้นว่าต้องไปตั้งค่าอะไรบ้าง เพื่อให้แอปเข้าสู่ระบบด้วย LINE
และส่งการแจ้งเตือนเป็นข้อความ LINE ได้

**สำคัญ:** โค้ดทั้งหมดพร้อมแล้ว สิ่งที่เหลือคือการตั้งค่าในหน้าเว็บ 3 ที่
(LINE Developers, Supabase, Vercel) ซึ่งต้องทำเอง เพราะเกี่ยวกับรหัสลับของบัญชีคุณ

ถ้ายังไม่อยากทำส่วน LINE ตอนนี้ ข้ามไปได้เลย — แอปยังใช้งานได้ครบทุกอย่าง
เข้าสู่ระบบด้วยอีเมลเหมือนเดิม และกระดิ่งแจ้งเตือนในแอปก็ทำงานอยู่แล้ว

---

## ขั้นที่ 0: รัน SQL ก่อน (จำเป็นเสมอ)

เข้า Supabase > SQL Editor > New query แล้วรันไฟล์สองไฟล์นี้ตามลำดับ
(เปิดไฟล์จากโฟลเดอร์ `supabase/migrations` แล้วคัดลอกทั้งไฟล์ไปวาง)

1. `0011_notifications.sql` — ระบบแจ้งเตือนในแอป (กระดิ่ง)
2. `0012_line_integration.sql` — ช่องเก็บข้อมูล LINE + ตัวช่วยส่งข้อความ

รันซ้ำได้ไม่มีปัญหา ทุกคำสั่งเขียนให้รันซ้ำได้อยู่แล้ว

หลังรัน 0011 เสร็จ กระดิ่งแจ้งเตือนในแอปจะใช้งานได้ทันทีโดยไม่ต้องพึ่ง LINE

---

## ขั้นที่ 1: สร้าง LINE Login channel (สำหรับปุ่มเข้าสู่ระบบ)

1. เข้า https://developers.line.biz/console/ แล้วล็อกอินด้วยบัญชี LINE
2. สร้าง Provider ใหม่ (หรือใช้ของเดิมที่มีอยู่)
3. สร้าง channel ชนิด **LINE Login**
4. ไปที่แท็บ **Basic settings** จดค่า **Channel ID** ไว้ → นี่คือ `LINE_LOGIN_CHANNEL_ID`
5. ไปที่แท็บ **LIFF** > Add
   - Endpoint URL: `https://challenge-me-one.vercel.app` (โดเมนจริงของคุณ)
   - Size: **Full**
   - Scopes: ติ๊ก **profile** และ **openid** (ต้องมี openid ไม่งั้นจะไม่ได้ ID token)
   - กด Add แล้วจดค่า **LIFF ID** ไว้ → นี่คือ `EXPO_PUBLIC_LIFF_ID` และ `LIFF_ID`

---

## ขั้นที่ 2: สร้าง Messaging API channel (สำหรับส่งข้อความ)

1. ใน Provider เดียวกัน สร้าง channel ชนิด **Messaging API**
   (ถ้ามี LINE OA อยู่แล้ว เชื่อมอันเดิมได้เลย)
2. แท็บ **Basic settings** > จด **Channel secret** → `LINE_CHANNEL_SECRET`
3. แท็บ **Messaging API** > กด Issue ที่ **Channel access token (long-lived)**
   → จดไว้ → `LINE_CHANNEL_ACCESS_TOKEN`
4. ในแท็บเดียวกัน:
   - **Webhook URL**: `https://challenge-me-one.vercel.app/api/line/webhook`
   - เปิด **Use webhook**
   - ปิด **Auto-reply messages** และ **Greeting messages**
     (ไม่งั้นบอทจะตอบข้อความอัตโนมัติทับของเรา)

---

## ขั้นที่ 3: ใส่ค่าใน Vercel

เข้า Vercel > โปรเจกต์ > Settings > **Environment Variables** แล้วเพิ่มทีละตัว
(เลือก Environment เป็น Production ทั้งหมด)

| ชื่อตัวแปร | ค่าที่ใส่ | เปิดเผยได้ไหม |
|---|---|---|
| `EXPO_PUBLIC_LIFF_ID` | LIFF ID จากขั้นที่ 1 | เปิดเผยได้ |
| `LIFF_ID` | ค่าเดียวกับด้านบน | ลับ |
| `LINE_LOGIN_CHANNEL_ID` | Channel ID จากขั้นที่ 1 | ลับ |
| `LINE_CHANNEL_SECRET` | Channel secret จากขั้นที่ 2 | ลับ |
| `LINE_CHANNEL_ACCESS_TOKEN` | Access token จากขั้นที่ 2 | ลับ |
| `SUPABASE_SERVICE_ROLE_KEY` | Supabase > Settings > API > service_role | **ลับมาก** |
| `LINE_TASK_SECRET` | สุ่มข้อความยาว ๆ มาเอง | ลับ |

### ⚠️ ข้อควรระวังที่สำคัญที่สุดในเอกสารนี้

**ห้ามเติม `EXPO_PUBLIC_` นำหน้าตัวแปรที่เป็นความลับเด็ดขาด**

ตัวแปรที่ขึ้นต้นด้วย `EXPO_PUBLIC_` จะถูกฝังลงในไฟล์ที่ผู้ใช้ทุกคนดาวน์โหลดไป
เปิดดูได้ด้วยการกดคลิกขวา > View source

โดยเฉพาะ `SUPABASE_SERVICE_ROLE_KEY` — คีย์นี้ข้ามระบบความปลอดภัยได้ทุกตาราง
ถ้าหลุดออกไป ใครก็อ่าน/แก้/ลบข้อมูลของผู้ใช้ทุกคนได้ทันที

เอาไว้เป็นหลักจำง่าย ๆ: ในตารางข้างบน มีแค่ `EXPO_PUBLIC_LIFF_ID` ตัวเดียว
ที่ขึ้นต้นด้วย `EXPO_PUBLIC_` ได้ นอกนั้นห้ามทั้งหมด

หลังเพิ่มตัวแปรครบแล้วต้อง **Redeploy** หนึ่งครั้ง ค่าถึงจะมีผล

## ขั้นที่ 4: ทดสอบ

1. เปิด `https://challenge-me-one.vercel.app` ในเบราว์เซอร์
   → ควรเห็นปุ่มเขียว **"เข้าสู่ระบบด้วย LINE"** โผล่ขึ้นมาเหนือช่องอีเมล
   (ถ้าไม่เห็น แปลว่า `EXPO_PUBLIC_LIFF_ID` ยังไม่ถูกใส่หรือยังไม่ได้ redeploy)
2. กดปุ่ม → LINE จะถามยืนยัน → กลับมาแล้วควรเข้าแอปได้เลย
3. ไปที่แท็บ **Me** → ชื่อควรเป็นชื่อ LINE ของคุณ และมีรูปโปรไฟล์ LINE
   กดที่ชื่อเพื่อแก้เป็นชื่ออื่นได้
4. ทดสอบการแจ้งเตือน: ให้เพื่อนอีกคนกดให้กำลังใจ Challenge ของคุณ
   แล้วดูกระดิ่งที่มุมขวาบนของหน้า Home → ควรมีตัวเลขแดงขึ้น
5. ทดสอบส่ง LINE: เปิด `https://challenge-me-one.vercel.app/api/line/notify?key=<LINE_TASK_SECRET>`
   → ถ้ามีเรื่องด่วนค้างอยู่ ควรได้ข้อความเข้า LINE

---

## ขั้นที่ 5: Rich Menu (ทำทีหลังได้)

Rich Menu คือแถบเมนูที่ปักอยู่ล่างหน้าแชท LINE ตลอดเวลา ทำหน้าที่เหมือนไอคอนแอป

1. เตรียมรูปขนาด **2500 x 843 px** แบ่งซ้าย-ขวา
   (ซ้าย = "เปิดแอป", ขวา = "ดูอัปเดตของฉัน")
2. เรียก `https://challenge-me-one.vercel.app/api/line/richmenu?key=<LINE_TASK_SECRET>`
   → ระบบจะสร้างเมนูพร้อมปุ่มสองช่องให้
3. เข้า LINE Official Account Manager > Rich menu → อัปโหลดรูป แล้วตั้งเป็นเมนูเริ่มต้น

## เรื่องโควตาข้อความที่ต้องรู้

LINE OA แพ็กเกจฟรีในไทยส่งข้อความแบบ push ได้ประมาณ **300 ข้อความต่อเดือน**
และนับ **ต่อผู้รับ** (ส่งหา 10 คน = 10 ข้อความ)

ระบบนี้ออกแบบมาให้อยู่ในโควตาแล้ว:

- **เรื่องด่วน** (มีคนท้าเรา / มีคนตอบคำถามเรา / มีคนส่งแรงผลักดัน) → ส่งทันที
  แต่ถ้าคนเดียวมีหลายเรื่องพร้อมกัน จะรวมเป็นข้อความเดียว
- **เรื่องทั่วไป** (มีคนให้กำลังใจ ฯลฯ) → รอรวมเป็นสรุปวันละครั้ง (ทุก 2 ทุ่ม)
- **ปุ่ม "ดูอัปเดตของฉัน"** ใน Rich Menu → ผู้ใช้กดดูเองได้ไม่จำกัด **ฟรี**
  เพราะข้อความตอบกลับไม่นับโควตา

ถ้าเริ่มมีผู้ใช้เยอะจนโควตาไม่พอ ทางที่ถูกที่สุดคือลดการส่งด่วนลง แล้วดันให้คน
ใช้ปุ่มดูอัปเดตเองมากขึ้น ก่อนจะไปอัปเกรดแพ็กเกจ

### หมายเหตุเรื่อง Cron ของ Vercel

ไฟล์ `vercel.json` ตั้งไว้ให้ตรวจเรื่องด่วนทุกชั่วโมง และส่งสรุปวันละครั้ง
แพ็กเกจฟรีของ Vercel จำกัดจำนวน cron ที่รันได้ ถ้าตั้งแล้วไม่ทำงาน
ให้ลบส่วน `"crons"` ออกจาก `vercel.json` แล้วใช้บริการ cron ฟรีข้างนอก
(เช่น cron-job.org) ยิงมาที่ URL สองอันนี้แทน:

- `https://.../api/line/notify?key=<LINE_TASK_SECRET>`
- `https://.../api/line/digest?key=<LINE_TASK_SECRET>`

## สรุปสิ่งที่ระบบทำให้อัตโนมัติแล้ว

| เหตุการณ์ | กระดิ่งในแอป | ส่ง LINE |
|---|---|---|
| มีคนท้าเราให้ทำ Challenge | ✓ | ทันที |
| มีคนตอบคำถามที่เราถามชุมชน | ✓ | ทันที |
| มีคนส่งแรงผลักดันมาให้ | ✓ | ทันที |
| Challenge กำลังจะหลุด | ✓ | ทันที |
| มีคนส่งกำลังใจให้ | ✓ | สรุปรายวัน |
| เพื่อนรับคำท้าของเรา | ✓ | สรุปรายวัน |
| มีคนมาเป็นผู้สนับสนุนของเรา | ✓ | สรุปรายวัน |

ผู้ใช้ปิดการแจ้งเตือนได้เองที่ `profiles.notifications_enabled` (ปิดทั้งหมด)
หรือ `profiles.line_notify_enabled` (ปิดเฉพาะทาง LINE แต่กระดิ่งในแอปยังทำงาน)
— ยังไม่ได้ทำปุ่มเปิด/ปิดในหน้าแอป ถ้าต้องการบอกได้
